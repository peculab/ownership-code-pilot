# Security policy

## Reporting

Do not publish a vulnerability, credential, personal record, private message, restricted source, or exploitable safety bypass in an Issue.

Email `peculab.ai@gmail.com` with:

- A concise description and affected component.
- Reproduction steps using non-sensitive fixtures.
- Potential impact.
- A safe way to contact you.

Do not access, modify, download, or contact real accounts or people beyond what is necessary to demonstrate the issue safely.

## Supported versions

The project is pre-alpha. Only the latest `main` branch is maintained. No production-security guarantee is made.

## Secrets

If a credential is exposed, revoke or rotate it immediately. Removing a file does not erase Git history.
