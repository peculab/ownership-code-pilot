# 實驗

研究文件背後的小型、可重現實驗紀錄。每個實驗有自己的資料夾，命名為 `YYYY-MM-DD-<主題>-<輪次>/`，內含：

- `README.md`（以及可選的 `README.zh-TW.md`）：問題、材料、程序、結果、觀察、詮釋、限制
- 作答者實際看到的材料
- CSV 格式的原始結果

規則：只能使用合成或核准過的資料；作答者匿名（`labeler-1`、`labeler-2`……），不記錄姓名、聯絡方式或個人資訊。事實、詮釋和模型輸出分開記錄在不同區塊。
