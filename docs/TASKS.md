# Open contribution tasks

These tasks use synthetic or public inputs and can begin without private partner material. Comment on an Issue before larger work so contributors do not duplicate effort.

| Task | Reviewable outcome |
| --- | --- |
| [#8 [Research] Propose a pain-point taxonomy for the synthetic scenarios](https://github.com/peculab/ownership-code-pilot/issues/8) | A documented v1 taxonomy and labels for 12 synthetic questions |
| [#9 [Design] Sketch the human-review and handoff states](https://github.com/peculab/ownership-code-pilot/issues/9) | An accessible wireframe for approve, revise, reject, and human takeover |
| [#10 [Evaluation] Define the first fixture and result schema](https://github.com/peculab/ownership-code-pilot/issues/10) | JSON Schema or documented schema for safe, reproducible fixtures and results |
| [#11 [Engineering] Implement a provider-neutral mock workflow contract](https://github.com/peculab/ownership-code-pilot/issues/11) | A no-network mock flow from synthetic input to reviewable draft |
| [#12 [Docs] Run a newcomer test of the public contribution path](https://github.com/peculab/ownership-code-pilot/issues/12) | A friction log and focused documentation fixes |
