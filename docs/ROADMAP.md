# Roadmap

## 0. Public foundation — current

- Publish challenge, safety, data, contribution, and evaluation rules.
- Create synthetic fixtures and provider-neutral contracts.
- Open small, independent starter tasks.

## 1. Reproducible baseline

- Implement mock input → classify → retrieve → draft → review flow.
- Evaluate a versioned fixture set.
- Document setup, cost, failures, and limitations.

## 2. Ownership Code example

- Add only explicitly approved, de-identified source cards.
- Compare the reusable baseline with the domain configuration.
- Conduct structured review without automatic external outreach.

## 3. Additional use cases

- Invite another organization or community to add a separate example.
- Test which components generalize and which remain domain-specific.

## 4. Optional deployment

Production integration, private data, maintenance, support, or paid model usage is outside the open-source pilot and requires its own owner, budget, risk review, and agreement.

Dates are intentionally not promised. Each milestone advances only when its evidence and safeguards are reviewable.
