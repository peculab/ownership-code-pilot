# Ownership Code example

Ownership Code contributed the first business scenario: helping a human team understand recurring business-owner questions, retrieve relevant approved experience, and prepare useful responses for review.

This directory will contain only synthetic or explicitly approved, de-identified configuration and fixtures. It must not contain prospect lists, private community posts, meeting transcripts, account exports, or messages to real people.

## Proposed first scenario

Given a synthetic question from a business owner, identify the underlying need, select relevant approved case cards, draft an educational response with sources and uncertainty, and recommend one of:

- `review_and_reply`
- `ask_for_context`
- `human_takeover`
- `do_not_respond`

No action is sent automatically.
